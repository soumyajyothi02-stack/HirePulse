# HirePulse – AI Resume Analyzer

HirePulse is an AI-powered resume analysis application that helps users understand and improve their resumes based on a specific job opportunity.

The application allows users to provide their resume details along with company and job information, and uses AI to provide relevant feedback and suggestions for improvement.

## 🚀 Features

* 📄 AI-powered resume analysis
* 🎯 Job-specific resume evaluation
* 🏢 Manual company and job information input
* 💡 Personalized improvement suggestions
* 📊 Resume insights and feedback
* 🖥️ Simple and user-friendly interface

## 🛠️ Tech Stack

* React
* JavaScript
* Google Gemini AI
* HTML & CSS
* Vite

## ⚙️ How It Works

1. Provide your resume information.
2. Enter the company and job details.
3. HirePulse analyzes the resume using AI.
4. Get feedback and suggestions to improve your resume.

## 💻 Getting Started

### Clone the repository

```bash
git clone <your-repository-link>
```

### Navigate to the project

```bash
cd HirePulse
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm run dev
```

Open the local URL displayed in the terminal to use the application.
